## การอ่านภาพและเกณฑ์ตรวจรับ

ภาพยาวแสดงปุ่มหลักที่ปลายภาพเพื่อไม่ทับเนื้อหา ปุ่มในเว็บจริงยังติดท้าย viewport และเว้นพื้นที่ตามความสูงจริงพร้อม safe area ภาพเต็มหน้าไม่ใช่การจำลองการ scroll หรือทดสอบอุปกรณ์จริง Footer/เมนูเดิมคงไว้ในการพัฒนา; หมายเหตุท้ายภาพเป็นข้อความกำกับงานตรวจแบบ

ขอให้ยืนยันการจัดวางชุดนี้ หรือระบุเลขภาพและจุดแก้ สามารถตอบรวมครั้งเดียว เช่น “ยืนยัน P03 ทุกภาพ” หรือ “แก้ภาพ 05 … และ 09 …” การอนุมัติผูกกับ `inventory.json` รุ่นปัจจุบันและ SHA ภาพ ไม่ขยายไปถึงราคาหรือข้อมูลสังเคราะห์

ตามแผน P03 ต้องตรวจรับภาพก่อนเขียน visual UI ใน P06–P11 จึงยังไม่บันทึกว่างานผ่านหรือมีวันอนุมัติ งาน P04/P05 ไม่ได้เริ่มระหว่างรอตรวจรับ เพื่อคงลำดับ task ตามคำสั่งผู้ใช้

รายละเอียดการออกแบบและข้อกำหนดที่ต้องรักษาอยู่ [design-brief.md](design-brief.md) หลักฐาน layout อยู่ [layout-checks.json](layout-checks.json) การชำระเงินจริงและอุปกรณ์จริงยังรอ User Test ตามที่ตกลง

## ผลตรวจรับ

ผู้ใช้ตอบ “ยืนยัน P03 ทุกภาพ” โดยตรงในแชตนี้ บันทึกเวลาอนุมัติและหลักฐานคำตอบใน `approval.json` ผูกกับ SHA ของ PNG ทั้ง 25 ภาพใน `inventory.json` ภาพและข้อมูลสังเคราะห์ไม่เปลี่ยน การอนุมัติครอบคลุมการจัดวางเพื่อดำเนินการ P06–P11 ตามแผนเดิม ไม่ใช่ข้อมูลขายหรือการเปิดรับเงินจริง ข้อความรอตรวจรับในส่วนก่อนหน้านี้เป็นบันทึกขั้นเตรียม review ที่สิ้นสุดแล้ว
