# Approved Abstracts Presentation Groups Design

## Goal

เมื่อผู้ใช้เลือกตัวกรอง `ทั้งหมด` ในหน้า Approved Abstracts ให้รายการบทคัดย่อที่แสดงผลถูกแบ่งเป็นกลุ่มตามรูปแบบการนำเสนออย่างชัดเจน เพื่อไม่ให้รายการ Oral Presentation, Highlighted Poster Presentation และ Poster Presentation ต่อกันเป็นชุดเดียวจนอ่านยาก

## Scope

- แสดงกลุ่มตามลำดับ `Oral Presentation` → `Highlighted Poster Presentation` → `Poster Presentation`
- แสดงหัวข้อคั่นกลุ่มเฉพาะเมื่อเลือก `ทั้งหมด`
- คงลำดับรายการภายในแต่ละกลุ่มตามข้อมูลจาก PDF และผลลัพธ์หลังใช้ search/category/round filter
- ถ้ากลุ่มใดไม่มีผลลัพธ์หลังกรอง ให้ไม่แสดงหัวข้อนั้น
- เมื่อตัวกรองเลือกประเภทใดประเภทหนึ่ง ให้แสดงรายการแบบเดิมโดยไม่ใส่หัวข้อซ้ำ
- ใช้สีของหัวข้อให้สอดคล้องกับป้ายประเภทเดิม: ส้มสำหรับ Oral, เขียวสำหรับ Highlighted Poster และน้ำเงินสำหรับ Poster
- รองรับภาษาไทยและภาษาอังกฤษผ่านข้อความแปลที่มีอยู่/เพิ่มเฉพาะข้อความหัวข้อที่จำเป็น

## Chosen Approach

จัดกลุ่มในชั้นการแสดงผลของ `src/app/[locale]/approved-abstracts/page.tsx` หลังจาก `filterAcceptedAbstracts` คืนผลลัพธ์แล้ว โดยไม่แก้โครงสร้างข้อมูล PDF และไม่เพิ่ม API หรือเปลี่ยนกติกาการกรอง วิธีนี้ทำให้ตัวกรองยังเป็นแหล่งความจริงเดียว และทำให้หัวข้อกลุ่มสะท้อนผลลัพธ์ที่ถูกกรองจริงเสมอ

การวนแสดงผลจะใช้ลำดับประเภทที่กำหนดตายตัว และใช้รายการเดิมภายในกลุ่ม ไม่ sort หรือแก้ไขข้อมูลต้นฉบับเพิ่มเติม หากเลือกประเภทเฉพาะจะใช้เส้นทางการแสดงผลเดิมเพื่อลดความเปลี่ยนแปลงที่ไม่จำเป็น

## Visual Design

แต่ละหัวข้อกลุ่มเป็นแถบคั่นเต็มความกว้างของรายการ มีจุดสี/เส้นเน้นด้านซ้าย ชื่อประเภทภาษาเดียวกับ PDF และระยะห่างที่ทำให้เริ่มกลุ่มใหม่ได้ชัดเจน บนมือถือหัวข้อยังคงอ่านได้ในบรรทัดเดียวหรือห่อบรรทัดอย่างเป็นธรรมชาติ โดยไม่ทำให้รายการล้นแนวนอน

หัวข้อกลุ่มเป็น semantic heading ภายใน list และไม่ทำให้จำนวนผลลัพธ์รวมเปลี่ยนแปลง ป้ายประเภทบนแต่ละรายการยังคงอยู่เพื่อให้ข้อมูลแต่ละแถวสมบูรณ์เมื่อผู้ใช้เลื่อนหรือค้นหา

## Constraints and Non-goals

- ไม่เปลี่ยนข้อมูลใน `approvedRound1Abstracts.ts`
- ไม่เรียก API หรือเพิ่ม network request
- ไม่เปลี่ยนคำใน PDF และไม่เพิ่มวงเล็บให้ชื่อประเภท
- ไม่เปลี่ยนการทำงานของ search, round filter, category filter หรือ reset filter
- ไม่ปรับโครงสร้าง header หรือส่วนอื่นของเว็บไซต์
