# User Test ร้านของที่ระลึก (เงินจริง, PRIS-2026)

ทำร่วมกับ User Test ของ API โดย Pris รันในเครื่องและชี้ไปที่ API ผ่าน ngrok (spec §11.4)

## เตรียมก่อนทดสอบ

- มือถือต้องเข้าถึงได้ทั้ง Pris และ API ผ่าน URL สาธารณะ (เช่น ngrok ทั้งสองฝั่ง) โดย `NEXT_PUBLIC_API_URL` ของ Pris ชี้ไปที่ URL สาธารณะของ API
- ตั้ง `CORS_ORIGIN` ของ API ให้เป็น URL สาธารณะของ Pris
- ถ้า API อยู่หลังโดเมนฟรีของ ngrok ให้ตั้ง `NEXT_PUBLIC_API_NGROK=1` ใน env ของ Pris (CORS ของ API อนุญาตเฮดเดอร์ `ngrok-skip-browser-warning` อยู่แล้ว) แล้ว Pris จะส่งเฮดเดอร์นี้ในทุกคำขอ merchandise API ทั้งนี้ครอบคลุมเฉพาะคำขอ merchandise เท่านั้น หน้าอื่นของ Pris เช่น login อาจยังเจอหน้าเตือน ดังนั้นการใช้ tunnel แบบไม่ใช่โดเมนฟรีปลอดภัยกว่า
- ต้องรัน migration 0043, seed และเปิดร้านบน API ก่อน (runbook §1, §4)

## ทุกอุปกรณ์ตรวจ

- [ ] 1. เปิดลิงก์ตรงโดยไม่ล็อกอิน → ล็อกอิน → กลับหน้าเดิม และ intent เพิ่มลงตะกร้าทำงาน
- [ ] 2. สั่งซื้อจริง → QR แสดง → บันทึกรูป (ปุ่มหรือกดค้าง) → เปิดแอปธนาคาร เลือกรูปแล้วจ่าย → กลับมาหน้าเดิม → สถานะเป็น `paid` เอง
- [ ] 3. รีเฟรชหรือปิดแล้วเปิดใหม่ระหว่าง `qr_active` แล้วเวลาไม่เริ่มใหม่
- [ ] 4. ปล่อยให้ QR หมดอายุ → `verifying` → “QR หมดอายุ” → “ขอ QR ใหม่” ได้ QR ใบใหม่ (reference ใหม่) บนออเดอร์เดิม
- [ ] 5. ปิดร้านขณะมี QR ที่ยังไม่หมดอายุ แล้วจ่ายได้ ส่วนออเดอร์ที่ QR หมดอายุหลังปิดร้านต้องเห็น “หมดเวลาชำระเงิน เนื่องจากปิดรับพรีออเดอร์แล้ว”
- [ ] 6. หน้าประวัติแสดงออเดอร์จ่ายแล้ว และข้อมูลจัดส่งหลัง Admin ใส่ tracking
- [ ] 7. เก็บหลักฐาน (ภาพหน้าจอที่ปิดข้อมูลส่วนตัวและไม่มี QR ที่ยังใช้ได้) ไว้ใน `docs/verification/merchandise-user-test/` เมื่อทดสอบจริง
